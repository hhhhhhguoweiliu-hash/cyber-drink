# AGENTS.md — Cyber Drink AI Rules

This is an existing WeChat mini-program codebase. Until the user defines a new product milestone, it is in maintenance/audit mode.

Before work read `.ai/PROJECT_BOARD.md`, `.ai/NIGHT_SHIFT.md`, `.ai/LEASE.md`, `app.json`, project config, and relevant pages/utils/assets.

Outcome-Review mode applies only to safe maintenance:
- repository inventory and documentation;
- syntax/config/package-size checks;
- deterministic bug fixes with clear evidence;
- non-destructive tests/checklists.

Do not invent new game/product features merely because the code could support them. New feature ideas go to IDEA INBOX.

No real WeChat publishing, credentials, paid services, production actions, or destructive data changes without explicit authorization.

Stable milestones: verify, update board/lease, commit, push `codex/night-shift`; never force or auto-merge main.
